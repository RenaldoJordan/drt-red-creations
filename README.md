# DRT RED CREATIONS Website

## Project Description

This is a colorful, responsive, multi-page website for **DRT RED CREATIONS**, a custom mug and tumbler business.

The site includes custom order functionality, vendor blank product information, an FAQ accordion, interactive forms, a live product preview, and a price estimate tool.

## Pages Included

- Home page
- Vendor Blanks page
- Custom Orders page
- FAQs page
- About Us page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- TypeScript
- Vite

## Features

- Responsive design for desktop, tablet, and mobile
- Sticky navigation bar
- Mobile menu toggle
- Vendor product filtering
- Vendor pricing request form
- Custom order form
- Live cup preview
- Color picker
- Font style selector
- Image/logo upload preview
- Quantity and rush order pricing
- FAQ accordion
- Scroll reveal animations
- Fake social media links for demonstration purposes
